# My Personal Portfolio 🚀

This is my personal portfolio website built with modern web technologies. It showcases my skills, projects, and provides a way to get in touch with me.

## ✨ Features
- **Modern Design**: A clean, "Gen-Z" inspired aesthetic with dark mode and vibrant accents.
- **Interactive Animations**: Smooth scroll-to-reveal animations and a creative "Solar System" skill navigation.
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop devices.
- **Contact Integration**: Connected via EmailJS for direct messaging.

## 🛠️ Technologies Used
- **Frontend**: HTML5, CSS3 (Custom properties & Animations), JavaScript (ES6+)
- **Icons**: DevIcons, Lucide-style SVGs
- **Deployment**: Vercel

## 📂 Project Structure
- `index.html`: The main structure of the site.
- `style.css`: Custom styling and mobile-first responsive design.
- `script.js`: Handles interactive elements like the typing effect and mobile menu.
